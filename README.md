Introduction and Project Objective:-
The primary objective of this data analytics project is to conduct a comprehensive Exploratory Data Analysis (EDA) on the global comic book market. 
Utilizing a robust dataset comprising over 10,000 distinct titles, this project transitions raw, unstructured data into actionable insights regarding 
publisher market share, pricing dynamics, and temporal publishing trends. By employing Python-based libraries (Pandas for data manipulation; Matplotlib and Seaborn 
for visualization), the workflow is documented systematically. The logic applied throughout this analysis prioritizes data integrity first—ensuring clean inputs—before
moving into complex visual interpretations. This approach allows for a transparent, reproducible methodology where every conclusion is strictly grounded in quantitative 
evidence.
